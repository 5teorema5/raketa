# Проект двухступенчатой ракеты с электромагнитным разделением

## 👥 Команда проекта

- **Арсений Лохматов** — автор идеи, тимлид
- **Алексей Козярский** — разработчик ПО
- **Кристина Рыжова** — инженер-моделист

## 📦 Используемое ПО

| Назначение | Продукт |
| :--- | :--- |
| Моделирование и расчёт устойчивости | **OpenRocket** |
| 3D-моделирование корпуса | **SolidWorks** / **Компас3Д** |
| Программирование контроллера | **Visual Studio Code** / **C** |
| Редактирование документации | **Obsidian** |

## 🔧 Основные компоненты

- **Контроллер**: Raspberry Pi Pico
- **IMU (акселерометр + гироскоп)**: MPU6050
- **Аккумуляторы**: LiPo 2S (7.4В) для поджига, LiPo 1S (3.7В) для логики
- **Система разделения**: электромагнитные катушки (медная проволока)
- **Система спасения**: вышибной механизм (пружинный / электромеханический)
